DIVINE UCHENNA PORTFOLIO V3
===========================

Open index.html with VS Code + Live Server.

Pages:
- index.html   Home
- about.html   Know Me Better
- services.html Services
- pricing.html Pricing
- contact.html Contact

Features:
- Dark/light mode with saved preference
- Animated counters for experience, customers, projects and prices
- Clickable project/service cards with full-screen image viewer
- Escape key / outside click closes image viewer
- Scroll reveal animations
- Hover and 3D tilt interactions
- Mouse parallax hero
- Active navigation line
- Responsive layout
- Accessible alt text and reduced-motion support
- Contact form opens an email to nwanoruedivine@gmail.com

Important:
The uploaded images are used at their original provided resolution. No blur filter is applied to them.
The contact form is frontend-only for now. The next learning phase can connect it to a real backend/database.
